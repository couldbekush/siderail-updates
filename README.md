# Siderail updates

The update feed for [Siderail](https://couldbekush.github.io/siderail-updates/), a macOS menu bar app that turns the trackpad edges into brightness and volume sliders.

- `appcast.xml` is the Sparkle feed Siderail checks for updates.
- `updates/` holds the signed update archives the feed points to.
- `download/Siderail.zip` is always the latest version, with the install guide.

Only release files live here; the source is elsewhere.
